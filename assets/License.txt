The ui_*.png icons were drawn for this game.
coin.png (14x14): source not recorded. It is the cash pill icon and the coin in the coin flights, so it is in use and stays. It came in with edb1fc1 as the replacement for ico_coin.png, part of a 14x14 ico_*.png set added with the first town sprites (2a08088). When it came in, the game's credit read "Art: LimeZu" and covered all the art, so a LimeZu origin is not ruled out. No identical whole file exists in packs/, but icons there are mostly inside sprite sheets, so that does not settle it. Origin unproven.
